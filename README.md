# DonutMod (Fabric, Minecraft 1.21.11, Singleplayer)

Bauen:  ./gradlew build   -> build/libs/donutmod-0.1.0.jar in den mods-Ordner (+ Fabric API)
Vorher: Versionen in gradle.properties mit https://fabricmc.net/develop (1.21.11) abgleichen.
Gradle-Wrapper erzeugen: "gradle wrapper" oder Projekt aus dem Fabric-Template-Generator uebernehmen und src/ hineinkopieren.

Befehle: /sell  /ah  /ah <preis>  /order  /order <item> <menge> <preis pro Stueck>  /bal

Preise: aus Rezepten berechnet (Zutaten + 10 %), Rohstoffe nach Seltenheit; /sell/ah/order nutzen dieselben Preise (x1,25).
Easter Egg: Schild "WerIstDas88" bei X=8888, Z=8888 in der Overworld (erscheint, wenn man in die Naehe kommt).
